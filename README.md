# drop_ru_domain_finder

Сервис для отслеживания, анализа и проверки истории освобождающихся доменов (.ru, .su, .рф).

## Пользовательский сценарий (User Journey)

Сквозной сценарий работы пользователя (домейнера / аналитика) в веб-интерфейсе:

1. **Вход и каталог:** Пользователь переходит на главную страницу, видит счетчик актуального реестра доменов (`header-total-count`) и липкую панель фильтрации.
2. **Поиск и фильтрация (Google RE2):** Вводит поисковый запрос (или выбирает готовый чипс-пресет, например `^[a-z]{3,4}\.ru$`, фильтр по зоне `.ru`/`.su`/`.рф` или дате). Выдача мгновенно фильтруется.
3. **Изучение выдачи:** Пользователь просматривает таблицу данных с длиной символов, датой освобождения, авто-расчетом Punycode (`xn--...`) для кириллицы и кнопкой быстрого копирования `copy`.
4. **Режимы отображения:** Может переключиться между полным каталогом и «Топ-20 от AI» (на сегодня / на завтра) с экспертным обоснованием привлекательности доменов от LLM.
5. **Инспекция WHOIS и Архива:** Клик по строке домена открывает выезжающую справа панель (**Slide-over Drawer 440px** на базе HTML5 `<dialog>`) с паспортом WHOIS (TCI) и он-деманд кнопкой `[Запросить историю]` из Wayback Machine. Панель поддерживает закрытие по клавише `Escape` или клику вне области.
6. **Экспорт в CSV:** Пользователь нажимает кнопку «Экспорт CSV» в панели фильтров и получает скачанный файл `domains.csv` со всеми отфильтрованными доменами.

Сценарий полностью покрыт автоматическим e2e-тестом `test_criterion_11_full_user_scenario_e2e` в `tests/test_client_ui.py`.

## Возможности

- **Базовый функционал:** получение списка освобождающихся доменов, фильтрация по датам (сегодня / завтра), поиск.
- **Regex-поиск (RE2):** фильтрация по регулярным выражениям через `/api/domains?regex=...`.
- **Top-20:** умный выбор лучших доменов с использованием оценки и данных WHOIS.
- **Wayback Machine:** история снимков домена в веб-архиве (`/api/wayback?domain=...`).
- **Интерфейсы:**
  - Веб-приложение (FastAPI + Jinja2 UI в `templates/index.html`).
  - Консольная утилита (`cli.py`).
  - MCP-сервер для WHOIS (`mcp_whois.py`).

## Запуск

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запуск веб-сервиса:**
   ```bash
   uvicorn api:app --reload --port 8000
   ```
   Веб-интерфейс открывается в браузере по адресу `http://127.0.0.1:8000`.

3. **Запуск CLI:**
   ```bash
   python cli.py list
   python cli.py top
   ```

4. **Тесты:**
   ```bash
   pytest tests/
   ```
