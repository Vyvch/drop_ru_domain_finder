# drop_ru_domain_finder

Сервис для отслеживания, анализа и проверки истории освобождающихся доменов (.ru, .su, .рф).

## Возможности

- **Базовый функционал:** получение списка освобождающихся доменов, фильтрация по датам (сегодня / завтра), поиск.
- **Regex-поиск (RE2):** фильтрация по регулярным выражениям через `/api/domains?regex=...`.
- **Top-20:** умный выбор лучших доменов с использованием оценки и данных WHOIS.
- **Wayback Machine:** история снимков домена в веб-архиве (`/api/wayback?domain=...`).
- **Интерфейсы:**
  - Веб-приложение (FastAPI + Jinja2 UI в `templates/index.html`).
  - Консольная утилита (`cli.py`).
  - MCP-сервер для WHOIS (`mcp_whois.py`).

## Запуск

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запуск веб-сервиса:**
   ```bash
   uvicorn api:app --reload --port 8000
   ```
   Веб-интерфейс открывается в браузере по адресу `http://127.0.0.1:8000`.

3. **Запуск CLI:**
   ```bash
   python cli.py list
   python cli.py top
   ```

4. **Тесты:**
   ```bash
   pytest tests/
   ```
